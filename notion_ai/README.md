# Notion AI — третий агент ccfleet

Notion AI работает рядом с Claude и Codex: получает сообщения из Telegram и из вкладки
«Notion AI» в консоли панели, отвечает в Telegram (текст + голос) и может вести Codex
по шагам (каждый шаг подтверждает владелец).

## Установка

```bash
sudo bash notion_ai/install.sh
```

Нужен уже установленный балансер (`/opt/cc-limits`). Скрипт ставит Playwright с Chromium,
сервисы `notion-delegate` и `notion-ai-view` (включаются сразу) и `notion-ai-tg`
(его включает профиль «Notion AI · только он»), команды `notion-ai-reply`, `notion-ai-mode`,
`notion-ai-step`, `notion-delegate` и модуль панели `cc_notion_ai.py`.
Повторный запуск безопасен: прежние файлы остаются рядом с суффиксом `.bak_<время>`.

## Настройка — в панели

**⚙ Общие настройки → Notion AI · третий агент**:

1. **Ссылка на постоянный чат.** В Notion открой Notion AI, начни новый чат, скопируй его адрес
   (`https://app.notion.com/chat?t=…`) и нажми «Сохранить».
2. **Вход в Notion.** Впиши почту входа, «Сохранить», потом «Войти»: на почту придёт код —
   введи его там же. Не больше 3 входов в сутки.
3. **Ключ доступа к серверу.** Попроси Notion AI создать SSH-ключ и вставь публичную часть
   (`ssh-ed25519 AAAA…`). Ключи из панели помечены `ccfleet-notion-ai`, их можно убрать одной кнопкой.
4. **Инструкция для Notion AI.** Скопируй и отправь первым сообщением в постоянный чат.
5. **Проверить связь** — проверка ничего не отправляет ни в чат, ни в Telegram.

Там же: как к тебе обращаться, свой чат Telegram (пусто — как у Claude), голосовые ответы,
вкладка «Notion AI» в консоли.

## Файлы

| Где | Что |
|---|---|
| `/opt/cc-limits/notion_ai.json` | настройки (панель пишет сюда, сервисы читают отсюда) |
| `/root/notion_web/state.json` | вход в Notion (только root) |
| `/root/notion_web/api_token` | токен локального API `127.0.0.1:8893` |
| `/root/notion_ai_inbox/` | фото и файлы из Telegram для Notion AI |

Сервис `notion-delegate` держит «тёплое» окно чата, пока включён профиль Notion AI:
сообщение уходит за 1–2 секунды вместо ~20.
