# Ручная сборка сценария — демо 04.11.2026

По последним правкам Дениса из выбора убраны поиск и прежний подвал со счётчиком и Escape. У обеих моделей показаны Full, Оркестратор и отдельный Исполнитель; единственный служебный режим — модель + Notion, без ограничения срока.

Выбранные роли являются черновиком. Нажатия не обращаются к API переключения. Full/резерв допускают одну модель; пара требует явных оркестратора и исполнителя в любом порядке. Несовместимые варианты блокируются с причиной. Повторное нажатие снимает роль. «Очистить выбор» начинает новый черновик; «Вернуть текущий» восстанавливает действующий выбор. «Применить сценарий» доступна для завершённого изменённого выбора. Full и резерв требуют подтверждения всего сценария. Поля и обработчики Notion сохранены.

Демо: https://deskpharm.ru/cc-demo/ — только демонстрационные данные. `preview_runtime.py` извлекает HTML из исходного кода, подставляет фальшивые API и не импортирует рабочие консоли, аккаунты, ключи или команды делегирования. `manual_scenarios.py` — изолированная политика стенда. Реальные консоли/агенты не вызываются.

Предыдущий функциональный релиз 1.28.0 и отступ резерва установлены и проверены (`cc-profiles-simple_20261104/deployment-result.json: live_verified`, 11:00 Иркутск). Ручная сборка ролей и новый монолит в этот релиз не входят. Они остаются демо для одобрения.

## Контракт для следующей рабочей интеграции

- GET `/api/profiles`: `manual_scenario.choices={claude:null|full|orchestrator|executor|reserve,codex:...}`, текущая ревизия и фактические роли.
- POST `/api/profiles/scenario/apply`: обе `choices`, `revision`, при необходимости `confirm`. Сначала полная валидация совместимости/ревизии; одиночная ведущая или исполнитель, два Full, две ведущие, два исполнителя, резерв с другой ролью отклоняются без побочных эффектов.
- Обычный односторонний `/apply` не назначает ведомую автоматически. Смена ролей должна быть общей транзакцией существующего NativeProfiles: preflight, сохранение обеих сессий/моделей/effort, применение и откат, включая паузу/возобновление второй стороны. Политика демо сама этого не реализует.
- Права оркестратора сохраняются по прежнему аудиту: ведущая читает проект и пишет обмен; задания подтверждает человек, прежний предел ведомой — dev. Текстовый предел задания нельзя выдавать за физическую песочницу уже запущенной Full-консоли.
- Резерв не истекает по времени. Явно разрешённый автоматический резерв — отдельная прежняя настройка; возвращает всю предыдущую пару после восстановления доступности. Не включать его из обычного выбора ролей.
- Изменение в другом окне делает черновик устаревшим. До восстановления актуального выбора кнопка применения заблокирована.
