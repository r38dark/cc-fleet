# Единые окна профилей и резерва — кандидат дизайна

Демо: https://deskpharm.ru/cc-demo/ — демонстрационные данные.

Рабочая версия 1.28.0 содержит только функциональные изменения: Full / Оркестратор / Notion-резерв, отмену сроков профилей, прежний предел dev для подтверждаемых шагов; также сохранены подготовленные поиск моделей Codex и ввод Telegram во время ответа. Новая компоновка требует просмотра Денисом и не включена в устанавливаемый интерфейс.

`monolithic-ui.patch` подготовлен относительно корневого `cc_overview.py` 1.28.0; применять после одобрения командой `git apply --unidiff-zero preview/simple-profiles_20261104/monolithic-ui.patch`. Исходники добавленного оформления — `simple_profiles.js` и `simple_profiles.css`. Полный кандидат и браузерный стенд находятся в `/home/codextrial/work/cc-profiles-simple_20261104`.

Один центрированный контейнер на двух исполнителей: слева Claude, справа Codex; четыре рабочих выбора и два резерва. Настройки открываются в таком же контейнере, используют прежние обработчики полей Notion. На узком экране столбцы становятся строками с прокруткой.

Проверено Chromium: оба входа в выбор/настройки, направления оркестратора, Full, ручной/автоматический резерв, сохранение Notion, поиск/автозаполнение, черновики при polling, touch 390×844. Это тесты демонстрационного API, а не переключение рабочих консолей. Функциональная версия отдельно проверена с реальными GET-снимками без POST и изменения активных сессий.
